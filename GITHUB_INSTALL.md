# Update your existing GitHub Pages website

1. Download the **UPDATE** ZIP and extract it on your computer.
2. Open the GitHub repository that hosts the 1,500-question website.
3. Replace **only** the two files `notes.html` and `sw.js` at the repository root (beside `index.html`). Do not rename them and do not upload the ZIP itself.
4. Commit the changes and refresh the published website while connected to the internet.
5. If the old site persists, open `https://YOUR-SITE/repair.html` using your real website URL and select **Refresh website files**. This does not clear SBA answers stored in localStorage.

The revised HTML contains the original table snapshots **inside `notes.html`**; no assets folder change is required. The question bank, session options and score code are unchanged.

See `QA_10_PASS_REPORT.md` for review scope and limitations.
