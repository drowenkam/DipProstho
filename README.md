# Diploma in Prosthodontics — GitHub Pages Website

## Included
- `index.html`: 1,500 interactive SBAs with three levels, practice and timed exams, and progress tracking.
- `notes.html`: final 72-page Volume I notebook mobile reader.
- `assets/sba-questions.pdf`: Questions-only Volume II PDF (1,500 SBAs).
- `assets/sba-answers.pdf`: Answer key and available justifications PDF (1,500 SBAs).
- `assets/notes-volume-i.pdf`: original final Volume I revision notebook.

## Install
1. Extract the ZIP archive on a computer.
2. Upload **the extracted contents**, not the `.zip` file, to your GitHub repository root.
3. Keep `index.html`, `sw.js`, and the entire `assets/` folder at their shown relative paths.
4. In GitHub **Settings → Pages**, select **Deploy from a branch**, `main`, `/(root)`.
5. Allow the Pages build to finish and open the HTTPS URL on iPhone/iPad.

## Progress and offline access
Export current progress from the old website before updating. The online website saves responses locally; exports/imports are needed between devices. For full offline textbook access use the notebook's save-offline option or save its PDF in Files. Other PDFs are cached when opened, subject to iOS storage limits.

## Editorial status
The 1,500 items in both PDFs and the website are from the November 2026 audited data set; independent clinical peer review and full rewriting of older items remain incomplete. These are independent educational materials, not official college questions.
