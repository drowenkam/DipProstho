# GitHub Pages upload instructions

1. Download `Dip_Pros_GitHub_Upload_1500.zip`.
2. Unzip it. You should see `index.html`, `notes.html`, `sw.js`, `manifest.webmanifest`, `.nojekyll` and the `assets` folder.
3. Open your existing GitHub repository. Before replacing the site, **export any study progress** from its My progress screen.
4. Choose **Add file → Upload files**. Upload root-level files into the root folder, and the files within `assets` into the `assets` folder. GitHub web upload limits can require multiple upload batches.
5. To replace a file individually, open that file, click the edit pencil (or `...` → Edit file), and replace its content; alternatively upload new files over existing files in the same location if GitHub offers this option. Do not leave duplicate `app.js` or `questions.json` files in different directories.
6. Commit your changes to `main`. Confirm **Settings → Pages → Deploy from a branch → main / (root)**.
7. Visit the Pages HTTPS URL, do a hard refresh on your Mac, and check a 150-question mock, result marking, notebook reader, and the two PDF links.

**PDF links:** `assets/sba-questions.pdf` and `assets/sba-answers.pdf`.

**Storage:** Progress is saved locally; export/import is needed to move between iPhone and iPad. Updating a website should not be treated as a substitute for a progress backup.
